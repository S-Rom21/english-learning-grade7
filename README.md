# English Training – Grade 7

A free, browser-based English practice site designed for a Grade 7 learner and a Samsung/Android tablet.

## Learning structure

- 30-minute sessions on Monday, Wednesday, Friday and Sunday (16:00 is the suggested start time)
- Seven learning areas in every session: Vocabulary, Grammar, Reading, Listening, Writing, Translation and Viewing
- 784 vocabulary entries in four pools: previously learned textbook words, additional textbook words, Grade 7 core vocabulary and extension vocabulary
- Further textbook vocabulary is introduced in small batches; already learned vocabulary is revisited
- Session report with answer feedback, duration and automatic results where grading is reliable
- PDF report through the tablet's print dialog and CSV export for Excel

## Privacy and storage

No account, paid service, AI API or server-side database is required. Session results are saved in localStorage in the browser on the learner's tablet. They are not uploaded to GitHub. The same browser and device are required to retain the local history; clearing browser data can remove it. A PDF report can be saved and forwarded separately.

## Deployment

The static site is served from the repository root via GitHub Pages. The deployment workflow is in .github/workflows/pages.yml.

Deployment check: Pages build is managed by the GitHub Actions workflow in this repository.
