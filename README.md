# English Training – Grade 7

Free English practice website for a Grade 7 learner.

## Planned learning structure

- 30-minute sessions on Monday, Wednesday, Friday and Sunday
- Seven learning areas: vocabulary, grammar, reading, listening, writing, translation and viewing
- Session report with results and progress export
- Local browser storage; no paid hosting, subscription or AI API required

## Deployment

The site is intended for GitHub Pages. The website files and textbook vocabulary content will be added and validated before enabling the public learning URL.
